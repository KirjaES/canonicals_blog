## Установка и запуск

Установка зависимостей

```shell
yarn install
```

Запуск проекта

```shell
yarn run start
```

Запуск сторибука

```shell
yarn run storybook
```

Команды для билда

```shell
yarn run build-storybook
yarn run build
```
